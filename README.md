# Video Downloader Web —macOS releases

**Mac only. Requires macOS 13 or later and the Video Downloader Web companion app.**

This repository is for downloadable application installers, release notes and checksums. The original Swift and Go application sources are maintained privately; they are not included in this repository.

## Distribution status

Public installer publication is being prepared. No public installer is available yet. The current candidate is a development-signed, non-notarized beta. Distribution signing, notarization and public download-link checks must be completed before it is offered as a production installation.

The Chrome Web Store item is currently a draft and has not been submitted or published.

## Using the product

The Mac companion must be installed and running. It starts the local connection automatically. The extension detects media, saves video links to the Mac library and downloads permitted media. Use only media you own or have permission to download.

Third-party notices and applicable source archives are bundled in the application under `Contents/Resources/ThirdParty`.
