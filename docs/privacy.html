Privacy policy

Video Downloader Web · Publisher: EmptyDeck

Scope

This policy covers the Video Downloader Web Chrome extension and its separate Mac companion. They detect media on web pages and let you save links, watch media in a Mac library, or download media that you are permitted to download. macOS 13 or later and the running companion app are required.

Information handled by the product

The extension observes media request addresses and response types on visited pages. It reads video/source elements, page titles, poster metadata and, where browser rules permit, small video-frame previews. Media inspection and library/download features use the page and media URLs, referrer, browser user agent, title, creator, thumbnail, available quality, duration, size and download status. The Mac library can store playback positions. These are used for the visible media features, not an unrelated browsing-history or advertising service.

Relevant website cookies

When media inspection, playback, library saving or downloading needs your current website session, relevant source/media cookies may be read. These can include authentication cookies. Opening the media interface may start metadata inspection before you press Download. The extension reads applicable cookies; it does not provide a feature to change your website cookies or collect passwords typed into forms.

Where information goes

The extension communicates with the native companion at 127.0.0.1 on the same computer. The extension and companion also request the source pages, media hosts, content-delivery networks, and images needed for those features. Relevant session information is used for the applicable media request. Native playback can open a source provider’s player or page. Those services receive normal network request information and applicable cookies under their own policies, and third-party players may show ads or use their own analytics. The developer does not operate a browsing telemetry or advertising backend for this product.

Data categories

The features handle website content, page/media addresses and titles (web history), media network-request observation (user activity), and relevant authentication cookies. Network observation is used to find media; the extension does not add unrelated mouse, scroll or keystroke logging. Developer-account registration, payments and identity checks performed by the Chrome Web Store are separate from the extension’s user-facing data processing.

Local storage and retention

Interface preferences and normal-window download state are stored locally. Detected media is associated with individual tabs and uses browser session storage where available. The Mac stores library links, media/creator/thumbnail information, playback positions and download history in its application-support directory; files are saved to the chosen download folder. Cookies used by the companion are transient process data rather than permanent library cookie records. Some inspection/download operations use temporary cookie files, normally removed when the operation cleans up. Interruption can leave temporary data. Closing the local service releases its in-memory credentials. A saved signed media URL can itself contain a token and stays in the library until removed.

Incognito

Incognito requires the browser’s explicit Allow in Incognito setting. Private browser detections and job state are kept apart from normal-window records and are cleared with the private browser session. A heart click deliberately saves the link in the Mac library, including from Incognito. That library entry and an explicitly downloaded file remain after private windows close. Removing a heart does not delete a library item or a file. Source services and networks can retain their own records independently of the extension.

Your controls

Remove an item with Remove from Library. Delete downloaded files separately in Finder. Removing the extension removes its browser-side data. To remove Mac-side records, quit the app and remove its application-support data. Use browser/site cookie settings to manage the source website’s session. This product does not supply a developer-hosted user account or cloud copy of your video library.

Limited Use

Information obtained through Chrome APIs is used for the disclosed media-library and download functionality and its direct operation. It is not sold or used for personalized advertising, credit decisions, lending or unrelated purposes. It is shared only as needed for those features or where a permitted legal, security or ownership-transfer requirement applies. The developer does not run a service that lets people inspect users’ browsing data. Any diagnostic information you intentionally send for support is a separate voluntary disclosure. These practices follow the Chrome Web Store User Data Policy and its Limited Use requirements.

Website hosting and support

Public information and downloads are hosted by GitHub, which can process hosting access information under its own privacy policy. These pages add no analytics scripts. If you email support, the developer receives what you choose to send and the email provider processes the message. Avoid sending website cookies, passwords or financial documents in a support request. Contact imsejikpark@gmail.com with policy questions or requests about information you previously supplied for support.
