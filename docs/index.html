Video Downloader Web

Mac only. Requires macOS 13 or later and the Video Downloader Web companion app.

Detect web media, save links to a personal Mac video library, and download media you own or have permission to download. The Mac companion starts its local connection automatically.

Public beta download

Download the Mac DMG · ZIP, Chrome extension and checksums

This beta is not notarized by Apple. After trying to open it, if you trust the official download, use System Settings → Privacy & Security → Open Anyway for this app only. Apple instructions.

The Chrome Web Store review is pending submission/approval. Until the store listing is available, use the manual extension setup. Try the sample clip.

Source and distribution

This site and repository provide public product information and installer releases. The original Swift and Go application sources are maintained privately. Third-party notices and applicable source archives are bundled with the app.
